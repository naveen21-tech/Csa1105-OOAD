OOAD_UML_LAB_XMI - Umbrello-style XMI (XMI 1.2 / UML 1.x) converted from the PlantUML files.

One .xmi per diagram (45 files): <NN>_<System>_Class_Diagram.xmi, _UseCase_Diagram.xmi, _Activity_Diagram.xmi. Original combined files are in the other zip.
  Class Diagram, Use Case Diagram, Activity Diagram.

Open in Umbrello:  File > Open > choose a .xmi file.

Notes
- Generated by script from the .puml sources; model element counts were cross-checked against the sources.
- Not tested inside Umbrello itself (not available where this was built). If a file does not open, tell me the error message.
- Umbrello has no swimlanes: lanes are laid out as columns, and the lane name is stored in each activity's documentation.
- Decision (branch) questions are stored in the branch node's documentation; guards like [approved] are edge labels.
- <<include>> / <<extend>> are Dependency links carrying the include/extend stereotype.
- Layout is automatic; drag widgets to tidy up before printing.
